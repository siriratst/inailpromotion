# i-NAIL Beauty Supply

เว็บนำเสนอสินค้าเด่นและโปรโมชั่นภาษาไทย รองรับมือถือ พร้อมภาพที่ร้านจัดเตรียม

## Deploy บน Render

ใช้ Render Static Site โดยมี `render.yaml` สำหรับ Blueprint แล้ว

1. เปิด https://dashboard.render.com/select-repo?type=blueprint แล้วเชื่อมต่อ GitHub
2. เลือก `siriratst/inailpromotion` และ branch `main`
3. ตรวจสอบ Blueprint แล้วกด Deploy Blueprint
4. รอให้สถานะเป็น Live และใช้ URL ที่ Render แสดง

หรือเลือก New > Static Site เชื่อม repo เดียวกัน แล้วตั้ง:

| รายการ | ค่า |
| --- | --- |
| Branch | `main` |
| Root Directory | เว้นว่าง |
| Build Command | `node build.mjs` |
| Publish Directory | `dist` |

การเปิด GitHub Pages ไม่จำเป็นสำหรับ Render

## เปิดดูบนเครื่อง

เปิด `index.html` โดยตรง หรือใช้ `node build.mjs` เพื่อเตรียมไฟล์ใน `dist/` ไม่มีแพ็กเกจที่ต้องติดตั้ง

## รูปโปรโมชั่น

- `assets/tadee-halloween.jpg`: Tadee Halloween ราคา 399 บาท จากปกติ 556 บาทตามภาพ
- `assets/chrome-palette.jpg`: พาเลตผงขัดเล็บ Spr013 / Spr059 ไม่มีราคาระบุ

ไฟล์ถูกคัดลอกจากโฟลเดอร์ที่ผู้ใช้ระบุเข้า repo แล้ว เว็บออนไลน์ไม่ต้องเข้าถึงไดรฟ์ E: หลัง deploy

ยังไม่มีระยะเวลาโปรโมชั่น สต็อก หรือช่องทางติดต่อจากร้าน จึงไม่สร้างเงื่อนไขหรือปุ่มสั่งซื้อขึ้นเอง โลโก้ต้นฉบับยังอ่านจากไดรฟ์ G: ไม่ได้ ใช้ชื่อร้านและสีอ้างอิงจากภาพโลโก้ก่อน

## แก้ไขเนื้อหา

- `index.html`: ข้อความหน้าเว็บและการ์ดโปรโมชั่น
- `app.js`: ข้อมูลในหน้าต่างรายละเอียดสินค้า ต้องแก้ให้ตรงกับข้อมูลหน้าเว็บ
- `style.css`: รูปแบบการแสดงผล

ฟอนต์โหลดจาก Google Fonts และมีฟอนต์สำรองเมื่อไม่มีอินเทอร์เน็ต

## สติ๊กเกอร์คริสต์มาส

เพิ่มภาพจริงทั้งหมด 36 แบบจากโฟลเดอร์ Sticker ของร้านใน `assets/stickers/` รายการรหัสอยู่ใน `sticker-data.js` มีช่องค้นหารหัสและกรองตามชุดรหัส ราคาโปรโมชั่นสติ๊กเกอร์คริสต์มาส 39 บาท จากปกติ 59 บาท ตามข้อมูลที่ร้านยืนยัน แสดงราคาทั้งหน้ารายการและหน้ารายละเอียด สอบถามสต็อกและระยะเวลาโปรโมชั่นกับร้าน
