# i-NAIL Beauty Supply

เว็บไซต์ภาษาไทยสำหรับนำเสนอสินค้าเด่นและโปรโมชั่น รองรับมือถือ

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ ไม่ต้องติดตั้งแพ็กเกจหรือ build

- `index.html`: เนื้อหาและโครงสร้างหน้าเว็บ
- `style.css`: สีและรูปแบบการแสดงผล
- `app.js`: ข้อมูลสินค้า การค้นหา ตัวกรอง และรายละเอียดสินค้า

## สถานะข้อมูล

สินค้า ภาพจำลอง และโปรโมชั่นเป็นตัวอย่างสำหรับจัดวางหน้าเว็บ ยังไม่มีราคาขายจริงหรือช่องทางสั่งซื้อ ต้องเพิ่มข้อมูลจริงก่อนนำไปใช้ขาย โลโก้ที่แนบยังอ่านจากไดรฟ์ต้นทางไม่ได้ จึงใช้ตัวอักษรชื่อร้านและสีอ้างอิงจากภาพ

ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts และมีฟอนต์สำรองหากไม่มีอินเทอร์เน็ต
